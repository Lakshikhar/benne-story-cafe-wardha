# Benne Story – South Indian Café (Wardha)
React + Vite + Lucide only.

    npm install
    npm run dev
    npm run build

## Before launch
- Photos: add JPGs to `public/images/` named as in `src/data/menu.js` (e.g. `podi-dosa.jpg`). Missing ones show a styled placeholder.
- Brand name, phone, Instagram: edit `src/data/menu.js`. Also update title/meta in `index.html`.
- Founder photos: add `aishwarya.jpg` and `jitesh.jpg` to `public/founders/` (initials show until then).
- Order tray sends a WhatsApp message to the number in `BRAND.whatsapp` (src/data/menu.js). Confirm that number is on WhatsApp.
